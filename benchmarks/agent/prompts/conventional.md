You are building a small web application from the task below. Choose any
stack you like. Work only inside the current directory, which is empty. When
you are done, the directory must contain everything needed to run the
application, and you must report:

- the command that starts the application and serves HTTP on the port named
  by the `PORT` environment variable (bound to `127.0.0.1`), and
- the files you consider application-specific (the idea), as opposed to
  routing, servers, authentication, sessions, validation, headers, static
  serving, deployment, configuration and tests (the plumbing).

The application is judged by an HTTP acceptance suite that is not shown to
you; the task lists every behavior it checks. Write tests for what you build
and run them before you finish.
